# Gallery design rules

- Keep the orange focus outline on every `<select>` and on text inputs in the avatar generator at **1 px**. Reuse the shared rule in `apps/gallery/src/style.css` for new controls; do not add thicker local overrides.

# Landing copy and SEO

- Write public-facing gallery copy in Spanish from Spain. Keep the warm, playful voice, but make the product and the next action clear before using wordplay.
- Ground benefits in the package documentation and implementation. Do not invent usage figures, testimonials, guarantees, or performance claims.
- Use concrete language for headings, descriptions, and calls to action. Avoid generic marketing phrases and formulaic AI wording. Keep each line short enough for its place in the design.
- For search-facing copy, describe the actual product: a deterministic SVG avatar library with 13 original collections for JavaScript and TypeScript, with optional React integration. Keep the page title, meta description, visible heading, and body aligned with that intent.
- Use the installed `copywriting` and `copy-editing` skills when drafting or revising landing copy.
