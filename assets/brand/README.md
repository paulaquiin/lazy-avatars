# Siesta identity / Identidad Siesta

The logo is a fixed drawing based on the project's original Siesta round body,
sleeping eyes and Z marks. It is a brand asset, not a new generated-avatar output.
The collection code, seeds and snapshots are unchanged.
- `siesta-mark.svg`: primary mark, cream tile, warm gold character, forest ink.
- `siesta-mark-mono.svg`: dark silhouette with white face, for light backgrounds.
- `siesta-mark-inverse.svg`: white silhouette with dark face, for dark backgrounds.
- Palette: cream `#f3eddd`, gold `#ddb46b`, forest `#315647`, dark ink `#29483d`.
- Use at 24 px or larger; retain the viewBox and 8 units of external clear space.
- Pair with the text `lazy-avatars` in the application's own UI font. The SVGs
  contain no font, converted typeface outline, remote asset or third-party art.
- For decorative inline use remove title/role and add aria-hidden; when repeating
  meaningful inline marks, give their title IDs distinct names. Image elements
  isolate the SVG and should have an appropriate alt value.
