# Privacidad de la galería

La galería genera los avatares SVG en tu navegador. El código de la galería no envía la semilla a un servicio de imágenes, no incorpora analítica y no guarda ajustes en cookies ni en el almacenamiento local del navegador.

## Texto y enlaces para compartir

Cuando cambias el nombre o los ajustes, la galería actualiza la dirección de la página. Esa URL puede incluir el texto que has escrito. Si usas «Copiar enlace» y lo compartes, otras personas podrán ver sus parámetros. Usa datos ficticios cuando prepares un enlace público.

Al abrir un enlace compartido, el servidor que aloja la web recibe la URL solicitada, incluidos sus parámetros.

## Enlaces externos

La web enlaza a GitHub y npm para consultar el código y el paquete. Al abrir esos sitios, se aplican sus propias prácticas de privacidad.

## Consultas

Si tienes una pregunta sobre el funcionamiento de la galería, consulta la página de [contacto](https://lazyavatars.paulaquiin.com/contact/). Las incidencias de GitHub son públicas: no incluyas información sensible.
