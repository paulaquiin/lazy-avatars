lazy-avatars / SVG con personalidad

Una semilla.
Un poco de personalidad.

Un sello, un mosaico, un servidor o alguien que necesita una siesta. Elige tu estilo: el mismo texto siempre dibuja el mismo avatar.

Paleta personalizada

Formato #RGB o #RRGGBB. Al activarla, sustituye al tema.

Todo se dibuja en tu navegador. La URL contiene la semilla: usa datos ficticios al compartirla.

Llévatelo a tu proyecto

Instala npm install lazy-avatars@1.1.2. Trece colecciones y versión estable disponibles en npm. Paquete único desde 1.1.0: un único paquete con entradas /react, /web-component, /cli y /http. Código en el repositorio.
