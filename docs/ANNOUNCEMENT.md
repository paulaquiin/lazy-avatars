## English

lazy-avatars 1.0 is here: thirteen original SVG avatar collections for people,
teams, servers and bots. One seed, predictable output, no image service and no
runtime dependencies in the core. Includes typed React, web component, CLI and
self-hosted HTTP integrations, plus a gallery with custom palettes.

Install `lazy-avatars@1.0.0`. Adapters use the `@paulaquiin/lazy-avatars-*` names.
Code, original artwork and Siesta branding are MIT licensed. Explore the
[gallery](https://lazyavatars.paulaquiin.com/) and
[source, contracts and compatibility](https://github.com/paulaquiin/lazy-avatars).
